# UHIRED

I built UHIRED because I knew what it was like to leave an interview wishing I'd
explained my experience better. The idea was simple: enter a job description,
practice answering questions aloud, and get feedback on each answer.

It won **1st place, Phase 2 — Learn and Integrate**, in the **Microsoft Developers
AI Learning Hackathon (2024)**.

[Project story and demo](https://devpost.com/software/aitism) ·
[Microsoft's announcement](https://devblogs.microsoft.com/cosmosdb/meet-the-winners-microsoft-developers-azure-ai-azure-cosmos-db-learning-hackathon/)

## What I built

The hackathon application used Azure OpenAI for the conversation, Azure Speech
for speech recognition and playback, Azure Cosmos DB for storage, and
Next.js/TypeScript with Tailwind for the interface.

The linked submission records that 2024 project. I haven't verified whether the
hosted demo is still available. The new experiments in [Enterprise AI Lab](https://github.com/edsonsims/enterprise-ai-lab)
are separate work, rather than the original UHIRED source.
