# UHIRED

An AI interview-practice application created by Edson Henrique for the 2024
Microsoft Developers Azure AI & Azure Cosmos DB Learning Hackathon.

**Recognition:** first place, confirmed in
[Microsoft's winner announcement](https://devblogs.microsoft.com/cosmosdb/meet-the-winners-microsoft-developers-azure-ai-azure-cosmos-db-learning-hackathon/)
and the [Devpost submission](https://devpost.com/software/aitism).

## Product problem

Interview preparation benefits from practice that reflects the role being pursued.
The project lets a person supply a job description, practice responses through a
spoken interaction, and receive feedback and recommendations. This describes the
submitted product; it is not a claim of improved hiring outcomes.

## Technical scope

The published submission describes Azure OpenAI for conversational behavior,
Azure Speech for speech-to-text and text-to-speech, Azure Cosmos DB for data
storage, and Next.js/TypeScript with Tailwind for the interface. The
[submission and demo](https://devpost.com/software/aitism) provide the original
project context and development account.

The engineering questions connect product experience with system design: keeping
spoken interaction responsive, preserving conversational context, and making the
feedback useful for a particular job description. These remain useful subjects for
later evaluation; no latency or model-quality benchmark is asserted here.
